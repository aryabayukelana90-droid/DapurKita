# DapurKita — Website Resep & Perencanaan Menu

## Menjalankan website
1. Ekstrak ZIP ini.
2. Buka `index.html` di Chrome, Edge, atau browser lain.

## Pembaruan dalam paket ini
- Detail resep menggunakan layar penuh, bukan jendela kecil.
- Teks langkah memasak berada pada kolom lebar yang benar dan membungkus normal.
- Tata letak menyesuaikan layar komputer dan HP.
- Mempertahankan fitur yang tersedia pada file sumber, termasuk katalog resep, favorit, perencana menu, daftar belanja, dan login prototipe.

## Catatan login dan publikasi
Login pada versi ini adalah prototipe lokal. Data akun/favorit/menu tidak otomatis tersinkron antarperangkat dan belum cocok untuk keamanan akun sungguhan. Untuk akun publik yang aman, hubungkan ke layanan autentikasi dan database online.

## Publikasi gratis melalui GitHub Pages
1. Masuk ke https://github.com/ dan buat repository baru bernama `dapurkita`.
2. Unggah `index.html` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu Save.
5. Setelah deployment selesai, GitHub akan menampilkan URL publik, biasanya `https://USERNAME.github.io/dapurkita/`. Ganti USERNAME dengan nama akun GitHub kamu.
